1. Review your assigned issues on the [Issues page](https://github.com/Abdallah4Z/AttenX/issues)
2. Check `TEAM_ASSIGNMENTS.md` for your complete task list
3. Start with your Phase 1 issues (see `QUICK_REFERENCE.md`)
4. Update issue status as you make progress

## 🏷️ Label System

Issues are tagged with:
- **Phase labels**: `Phase 1: Foundation` through `Phase 5: Evaluation`
- **Priority**: `high`, `medium`, `low`
- **Status**: `ready`, `in-progress`, `blocked`
- **Category**: `Research and Design`, `Development and Training`, `Evaluation and Science`, `Environment and Baselines`
